RegionManager.Transition Method

Definition

Applies the regions the player is in.

Transition(initial, regions)

Parameters

initialbool
regionslist

regionmanager.py's region tuples (priority, enabledFlags, ambient, music, environment map, sky, display name id), sorted by priority.

Returns

None.

Remarks

Per enabledFlags bit the first region with it supplies that feature: bit 0 sky, 1 environment map, 2 ambient sound, 3 music, 4 the shown name (which calls client.gameui.DisplayRegionName). An empty list changes nothing.
