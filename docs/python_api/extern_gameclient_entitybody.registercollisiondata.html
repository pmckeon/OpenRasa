extern_gameclient_entitybody.RegisterCollisionData Function

Definition

Registers a model's collision shape.

RegisterCollisionData(meshName, shape, x, y, z)

Parameters

meshNamestr

The model.

shapeint

The shape.

ValueMeaning
1Sphere: radius x.
2Box: half extents (x, y, z).
3Capsule: radius x, half height max(y - x, 0).
4Upright cylinder: radius x, half height y.
xfloat
yfloat
zfloat

Returns

None.

Remarks

classmanager.py registers generated.client.collision's shapes; a body of that model gets the shape on bone 0 (centred) unless its model embeds one.
