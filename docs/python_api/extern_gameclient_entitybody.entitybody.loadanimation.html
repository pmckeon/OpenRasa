extern_gameclient_entitybody.EntityBody.LoadAnimation Method

Definition

Loads an animation without playing it.

LoadAnimation(name[, callback])

Parameters

namestr
callbackstr

The name of an entity method called with the asset name when it has loaded.

Returns

The animation's asset name (str).

Remarks

When it is playing and not looping it restarts instead; when it is playing and looping the callback runs at once.
