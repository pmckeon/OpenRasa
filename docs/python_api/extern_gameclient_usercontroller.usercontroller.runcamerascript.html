extern_gameclient_usercontroller.UserController.RunCameraScript Method

Definition

Runs a camera script (World.AddCameraScript).

RunCameraScript(id)

Parameters

idint

Returns

None.

Remarks

Only in CameraCut mode; an unknown id is logged ("Script id not found!"). When the script ends the camera returns to its starting pose and OnCameraScriptFinished() is called on the input state router.

Engine

tabula_rasa.exe: 0x004f56a0.
