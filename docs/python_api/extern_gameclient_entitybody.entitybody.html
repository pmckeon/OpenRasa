extern_gameclient_entitybody.EntityBody Class

Definition

An entity's body, made by CreateBody. physicalentity.py keeps it as entity.body. The class cannot be created from Python: its __init__ raises RuntimeError "This class cannot be instantiated from Python".

Base: EntityBodyBase

Properties

PropertyDescription
movementThe body's ClientMovingEntityController after RegisterAsMovingEntity, else None. Read-only.
