extern_gameclient_entitybody.StaticBodySetBounds Function

Definition

Sets a static map body's model-space bounding box.

StaticBodySetBounds(entityId, minBound, maxBound)

Parameters

entityIdlong

The map entity's id.

minBoundtuple

(x, y, z).

maxBoundtuple

(x, y, z).

Returns

None.

Remarks

The box, placed by the body's transform, decides which 50 m cells of the static grid the body is filed in.
