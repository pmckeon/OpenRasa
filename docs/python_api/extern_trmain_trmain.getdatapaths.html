extern_trmain_trmain.GetDataPaths Function

Definition

Gets the paths of the loadable data modules (Python zips) named in tabula_rasa.cfg.

GetDataPaths()

Returns

A list of str: the value of every key of the [Data] section, in the order the engine's config table iterates them (its hash order - alphabetical, ignoring case, while the section has four keys or fewer). Stock: ['data/game.zip'].

Remarks

clientbootstrap.py puts these on sys.path before importing the game data, so a zip named ahead of GameData can override modules of data/game.zip.

Engine

tabula_rasa.exe: FUN_00405480 (loads tabula_rasa.cfg; iterates the section with FUN_00478ac0).
