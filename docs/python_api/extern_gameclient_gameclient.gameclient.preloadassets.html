extern_gameclient_gameclient.GameClient.PreloadAssets Method

Definition

Requests the assets of a catalog (.cat) to be loaded, with an optional completion callback.

PreloadAssets(catalogName[, callable[, args]])

Parameters

catalogNamestr

The catalog, e.g. startup.cat.

callablecallable

Called as callable(*args) when the catalog has loaded (at once when it already has). None for no callback.

argstuple

The callback's arguments.

Returns

True.

Exceptions

ExceptionCondition
TypeErrorcallable is not callable.

Remarks

Catalogs are reference counted: each PreloadAssets needs a ReleaseAssets.
