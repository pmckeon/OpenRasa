extern_trmain_trmain.InitApp Function

Definition

Initialises the game application.

InitApp()

Returns

None.

Remarks

Sets up the application before the game client: the log ([Logging] in tabula_rasa.cfg: Enabled, unless "false"; File, default tabula_rasa.log), the window and the renderer.

OpenRasa

The application is set up before the scripts run; the call does nothing.
