extern_gameclient_gameclient.GameClient.Run Method

Definition

Runs the game loop until a quit is requested.

Run()

Returns

None, when the loop ends (PostQuitRequest).

Remarks

Each frame the engine pumps input, runs the scripts' scheduled methods and timers, streams the world and renders.
