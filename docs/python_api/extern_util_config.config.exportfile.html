extern_util_config.Config.ExportFile Method

Definition

Writes this Config to a file.

ExportFile(filename)

Parameters

filenamestr

The file's path.

Returns

None.

Exceptions

ExceptionCondition
RuntimeError"Unable to export file: <filename>".

Remarks

Written in text mode (CR LF line ends): per section [name], its key = value lines and a blank line. Sections are written ordered by name ignoring case, their keys in the order they were added. A name or value is written bare when every character is a letter, a digit or one of .,_-@:/ and it does not start with .; otherwise it is quoted, with \ and " escaped. Items copied from another section (.section, [a = b]) and empty sections are not written.
