extern_game_characterstatemachine.CharacterStateMachine Class

Definition

The posture state of a moving entity: standing, sitting, lying down, swimming, crouched, flying or flailing. The class cannot be created from Python: its __init__ raises RuntimeError "This class cannot be instantiated from Python".

Methods

MethodDescription
EnterStanding()Puts the character into the standing state.
EnterSitting()Puts the character into the sitting state.
EnterLyingDown()Puts the character into the lying down state.
EnterSwimming()Puts the character into the swimming state.
EnterCrouched()Puts the character into the crouched state.
EnterFlying()Puts the character into the flying state.
EnterFlailing()Puts the character into the flailing state.

Remarks

Each Enter method stores its state number (0 - 6) and nothing else; nothing in the engine was found to read it (UNVERIFIED).
