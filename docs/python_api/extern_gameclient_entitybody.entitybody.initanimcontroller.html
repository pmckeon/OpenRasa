extern_gameclient_entitybody.EntityBody.InitAnimController Method

Definition

Connects the body's animation markers to the scripts.

InitAnimController()

Returns

None.

Remarks

Markers of the playing animations then call the entity's OnMarker_Strike (1), OnMarker_WeaponSwing (3), OnMarker_WeaponSwing2 (4), OnMarker_PreStrike (29), OnMarker_WeaponDraw (61) and OnMarker_WeaponStow (62).
