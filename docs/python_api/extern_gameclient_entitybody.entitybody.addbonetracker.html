extern_gameclient_entitybody.EntityBody.AddBoneTracker Method

Definition

Adds a bone tracker: bones that turn to look at a target.

AddBoneTracker(id, bones)

Parameters

idint

The tracker's id (generated.client.bonetracking).

boneslist

Tuples (bone name, connection point or None, yaw weight, pitch weight, yaw accept, pitch accept, yaw limit, pitch limit, speed): weights 0 - 1, angles in degrees (0 - 180), speed in degrees a second.

Returns

None.

Remarks

A target outside the accept angles is ignored (the bone returns to 0); the turn is clamped to the limits and the speed. A tracker of that id that exists is kept.
