extern_gameclient_entitybody.EntityBody.GenerateCollisionBody Method

Definition

Gives the body a collision shape (the .map's generated ABVs).

GenerateCollisionBody(shape, x, y, z)

Parameters

shapeint
ValueMeaning
1Sphere: radius x.
2Box: half extents (x, y, z).
3Capsule: radius x, half height max(y - x, 0).
4Upright cylinder: radius x, half height y.
xfloat
yfloat
zfloat

Returns

None.

Remarks

The shape stands on the body's base (centred y above it). A static body applies it when it loads.

Engine

tabula_rasa.exe: 0x00500130.
