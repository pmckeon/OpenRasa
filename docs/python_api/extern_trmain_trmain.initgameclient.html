extern_trmain_trmain.InitGameClient Function

Definition

Initialises the game client.

InitGameClient()

Returns

True when the game client started; otherwise False, after an error dialog showing the log's contents.

Remarks

Builds the engine side of the client (the UI manager and its root window), then sets the UI script package client.ui, builds the uievent and uianchor modules, imports client.main, initialises the input state router and runs client.main.Initialize(), then loads the UI layout (Tabula_Rasa_UI_EXPORT.xml), whose windows import their scripts as they load. A script failure at any step makes it fail.
