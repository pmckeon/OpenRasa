WeatherManager Object

Definition

The sky clock and the scripted sky, returned by GameClient.GetWeatherManager (always the same object).

Methods

MethodDescription
SetLengthOfDay(ms)Sets the length of a day.
SetCurrentDate(day, time)Sets the sky clock.
CreateSkyLayer(layer, mesh, manualAnim, byRotation, rotsPerDay, x, y, z, w, qx, qy, qz)Creates a sky layer.
SetSkyLayer(layer, index, mesh)Sets a sky layer's model.
CreateSkyLight(layer, lensFlare, x, y, z)Creates a directional light on a sky layer.
CreateGlobalLight(lensFlare, x, y, z, hemi)Creates a global light.
AddLightColorKey(layer, light, time, aI, dI, sI, ambient, diffuse, specular, flag)Adds a colour key to a light.
AddLayerAlphaKey(layer, time, alpha)Adds an alpha key to a sky layer.
AddLayerOffsetKey(layer, time, x, y, z)Adds an offset key to a sky layer.
AddFogKey(time, distance, r, g, b)Adds a fog key.
EnableFogOverride(distance)Overrides the fog with one ending at a distance.
DisableFogOverride()Ends the fog override.
Reset()Removes every sky layer and light.

Remarks

A plain C object (PyCPPObject), every method taking positional arguments. Current maps take their skies from the regions' .sky files instead of the scripted-sky methods. Used only by .map formats 2.12 - 2.37 (gamemap.py _LoadSky3 / _LoadSky4 / _LoadDirLights1); no shipped map uses them.
