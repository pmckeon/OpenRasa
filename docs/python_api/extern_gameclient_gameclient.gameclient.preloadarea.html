extern_gameclient_gameclient.GameClient.PreloadArea Method

Definition

Loads the static map bodies around a point.

PreloadArea(position, radius[, wait])

Parameters

positiontuple

(x, y, z).

radiusfloat

The streaming radius; 0 or less uses the engine's own: 199 + 100 x ViewDistance / 100.

waitbool

True to wait until the asset loader has finished (actor.py after a teleport); wonkavator.py passes False.

Returns

None.

Remarks

Streams the static-body grid's cells around the point and creates / destroys every queued body at once.

Engine

tabula_rasa.exe: 0x004d6de0.
