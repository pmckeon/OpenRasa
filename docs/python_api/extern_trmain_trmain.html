extern_trmain_trmain Module

Description

The application module: start-up, shutdown, the game client object and the log. trmain.py (trpython.zip) imports it as trmain and drives the client's lifetime through it: InitApp, InitGameClient, then GetGameClient().Run().

Its functions are plain module functions (the module has no class).
