extern_gameclient_entitybody.CreateBody Function

Definition

Creates the body of an entity.

CreateBody(entityId, meshName[, lodMeshName[, lodScreenPercentage[, meshId]]])

Parameters

entityIdlong

The entity.

meshNamestr

The model (.geo).

lodMeshNamestr

A lower-detail model.

lodScreenPercentagefloat

The screen size below which the LOD model is used.

meshIdint

The model's string-table id.

Returns

The new EntityBody.

Remarks

In static mode (SetStaticMode) the body is a static map body: it gets an empty scene body and a load record in the static grid, and is loaded and unloaded as the camera streams the map; the StaticBody... functions then edit its record.
