extern_gameclient_entitybody.StaticBodySetTransform Function

Definition

Places a static map body.

StaticBodySetTransform(entityId, location, orientation[, scale])

Parameters

entityIdlong

The map entity's id.

locationtuple

(x, y, z).

orientationtuple

A quaternion (x, y, z, w).

scalefloat

Uniform scale, 1 by default.

Returns

None.

Remarks

Updates the body's load record (and its grid cells) and the body's own transform, which its sounds follow.
