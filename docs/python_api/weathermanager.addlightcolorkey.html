WeatherManager.AddLightColorKey Method

Definition

Adds a colour key to a light.

AddLightColorKey(layer, light, time, aI, dI, sI, ambient, diffuse, specular, flag)

Parameters

layerint
lightint

The light's id.

timefloat

0 - 1.

aIfloat

Not used.

dIfloat

The intensity.

sIfloat

Not used.

ambientint

Not used.

diffuseint

0xRRGGBB.

specularint

Not used.

flagint

For a hemispheric light 128 or more = the bottom colour.

Returns

None.

Remarks

The key's colour is dI x diffuse / 255.
