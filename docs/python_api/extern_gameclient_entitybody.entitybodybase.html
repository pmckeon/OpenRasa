extern_gameclient_entitybody.EntityBodyBase Class

Definition

The base of EntityBody: place, rotation, flags, distances and decoration points. The class cannot be created from Python: its __init__ raises RuntimeError "This class cannot be instantiated from Python".

Remarks

Yaw is the rotation about the vertical in radians; a body with yaw r faces (-sin r, 0, -cos r). Connection point ids are the numbers of generated.client.connectionpoint (e.g. 28 = HPS_VFX1); contact ids are a model's own contact point numbers.
