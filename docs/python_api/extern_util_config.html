extern_util_config Module

Description

The engine's configuration files: the Config class reads and writes the .cfg format of tabula_rasa.cfg, login.cfg and TRBookmarks.bmf.

Unlike the other modules' classes, Config can be created from Python (extern_util_config.Config()); the engine itself makes two at start-up, returned by GetAppConfig and GetLoginConfig.
