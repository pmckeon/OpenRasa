extern_gameclient_usercontroller.UserController.PanCamera Method

Definition

Moves the camera in or out (the mouse wheel).

PanCamera(farther)

Parameters

fartherbool

True to move out.

Returns

None.

Remarks

Normal: the zoom (0 - 1, 1 farthest) changes by 0.1; Detached: the wheel flags move the free camera.

Engine

tabula_rasa.exe: 0x004f6b10.
