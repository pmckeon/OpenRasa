extern_gameclient_clientmovingentitycontroller Module

Description

The movement controller of an entity body, made by EntityBody.RegisterAsMovingEntity and returned by the body's movement property.

Attributes

NameDescription
MovingEntityControllerClass - The base movement controller.
ClientMovingEntityControllerClass - The client's movement controller: it moves the player's body from input and server-driven bodies from the server's movement messages, with their facing and turning.

FunctionDescription
CreateWrapper(object)Returns its argument unchanged.
