extern_gameclient_entitybody.EntityBodyBase.SetYaw Method

Definition

Sets the body's yaw.

SetYaw(yaw)

Parameters

yawfloat

Radians.

Returns

None.

Remarks

Yaw is the rotation about the vertical in radians; a body with yaw r faces (-sin r, 0, -cos r). The rotation becomes D3DXQuaternionRotationYawPitchRoll(yaw, 0, 0).
