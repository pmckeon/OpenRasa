extern_gameclient_entitybody.EntityBodyBase.GetDecorationPointSockets Method

Definition

Gets the model's decoration sockets.

GetDecorationPointSockets()

Returns

A list of (connection point id, contact id).

Remarks

Connection point ids are the numbers of generated.client.connectionpoint (e.g. 28 = HPS_VFX1); contact ids are a model's own contact point numbers.
