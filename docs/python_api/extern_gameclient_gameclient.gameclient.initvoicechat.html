extern_gameclient_gameclient.GameClient.InitVoiceChat Method

Definition

Starts voice chat.

InitVoiceChat()

Returns

True when the voice client exists or was made; False without the audio manager.

Remarks

Voice activation is Client.Voice.Activated and not ListenOnly (both default False); ActivationLevel (default 190) and CutoffDelay (default 300) are at least 100; then VoiceVolume.
