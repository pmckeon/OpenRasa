extern_gameclient_gameclient.GameClient.ParseDLCommand Method

Definition

Runs a renderer debug view command (chat /dl_<name>).

ParseDLCommand(command[, value])

Parameters

commandstr

dl_<name> (the first three characters are skipped).

ValueMeaning
showresultBack to the normal view (only clears).
shownormalsThe G-buffer's normals.
showdepthDepth.
showdiffuseThe albedo buffer.
showspecpowerSpecular power.
showspecintensitySpecular intensity.
showglowGlow.
showedgesEdges.
showdifflightDiffuse light.
showspeclightSpecular light.
showlightThe light buffer (light x 0.2).
hqtToggles render bit 16.
overdrawToggles the overdraw view.
overdrawexpertToggles the expert overdraw view.
complexityToggles the shader complexity view.
fsaaToggles full-screen antialiasing.
on / offDeferred lighting on / off (Custom video quality only).
shadowon / shadowoffDynamic shadows (Custom only).
fakeshadowon / fakeshadowoffFake shadows (Custom only).
specon / specoffSpecular lighting (Custom only).
32 / 6464-bit lighting off / on.
mip<n>A texture mip setting.
flushFlushes a renderer cache.
valueobject

Optional.

Returns

None.

Remarks

Every debug view bit is cleared first, then the command's set. The G-buffer views appear only with deferred lighting.

Engine

tabula_rasa.exe: FUN_004d6580.
