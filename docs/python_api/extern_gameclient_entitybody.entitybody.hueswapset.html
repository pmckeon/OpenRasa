extern_gameclient_entitybody.EntityBody.HueSwapset Method

Definition

Colours a swap set's pieces.

HueSwapset(swapset, hue[, skin])

Parameters

swapsetint
huetuple or None

(r, g, b, a) 0 - 255 for the item; None = grey (0.5).

skintuple or None

The skin colour, for the pieces of group flesh.

Returns

None.

Remarks

Each piece of the swap set gets the skin colour when given and the piece is flesh, else the item colour, as its Hue.

Engine
