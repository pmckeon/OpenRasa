extern_trmain_trmain._WriteLog Function

Definition

Writes an entry to the log file.

_WriteLog(severity, format, args)

Parameters

severityint

The severity level.

ValueMeaning
0TRACE
1DEBUG
2INFO
3WARNING
4ERROR
5ASSERT
6FATAL
formatstr or unicode

The text, or a % format string when args is not None.

argsobject

None, or the value(s) for format % args.

Returns

None.

Remarks

Nothing is written unless _ShouldLog(severity) is True. The text is format when args is None, else format % args; when that fails, Format Error: <repr(format)> % <repr(args)>. Unicode text is written as ASCII, or as its repr when it is not ASCII; a value that is not a string is written as [Non-string object could not be translated to ASCII for logging].

The line is LEVEL: text with the level's name (none past 6). Levels 0 - 2 go to the log; 3 and above go through the engine's error handler, which writes the same line (and, for ASSERT / FATAL, may show its dialog).

OpenRasa

Written to the standard error stream, not the log file; the error handler's dialog is not shown.

Engine

tabula_rasa.exe: FUN_004050b0 (log FUN_00705e70, error handler FUN_007066d0).
