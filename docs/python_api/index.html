Python API

The engine objects tabula_rasa.exe exposes to the client scripts (trpython.zip), as traced in the executable and implemented in OpenRasa. Each module is registered at start-up by the engine; its classes cannot be instantiated from Python - the engine hands out the instances.

Modules

ModuleDescription
extern_trmain_trmainThe application module: start-up, shutdown, the game client object and the log.
extern_gameclient_entitybodyEntity bodies: the engine side of every entity the client shows - its model, place, animation, effects, sounds and collision.
extern_gameclient_clientmovingentitycontrollerThe movement controller of an entity body, made by EntityBody.RegisterAsMovingEntity and returned by the body's movement property.
extern_game_characterstatemachineA character's posture state, held by its movement controller (ClientMovingEntityController.characterstatemachine).
extern_gameclient_gameclientThe game client: the engine's top-level object for the scripts - managers, networking, map loading, assets and debugging.
extern_gameclient_optionsmanager_wrapThe options tree: client, user and character settings.
extern_gameclient_option_wrapThe nodes of the options tree (OptionsManager).
extern_gameclient_usercontrollerThe user controller: the player's camera, movement input, picking and targeting.
extern_gameclient_worldThe game world: terrain, collision, line of sight, picking and camera scripts.
extern_util_configThe engine's configuration files: the Config class reads and writes the .cfg format of tabula_rasa.cfg, login.cfg and TRBookmarks.bmf.

Objects

ObjectDescription
LightManagerThe scripted light manager, returned by GameClient.GetLightManager.
RegionManagerThe map regions' features (sky, environment map, sounds, music, name), returned by GameClient.GetRegionManager (a new object each call).
SfxPackageA special-FX package playing on a body, returned by EntityBody.AttachFXPackage and its variants.
WeatherManagerThe sky clock and the scripted sky, returned by GameClient.GetWeatherManager (always the same object).

Conventions

Signatures list the arguments the engine parses; [, x] marks an optional one. Types are Python 2.4's: int, long (entity ids are 64-bit and arrive as long), float, str, unicode, bool (any object; its truth is used unless noted).

The Engine section names the function in tabula_rasa.exe (client 1.16.5.0) that implements the method: an address 0x... is the bound function itself, FUN_... the routine it calls. UNVERIFIED marks behaviour read from the code but not checked against the running game.

An OpenRasa note says where OpenRasa does not reproduce the engine's behaviour exactly.
