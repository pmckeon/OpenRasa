extern_gameclient_optionsmanager_wrap.OptionsManager.SetOptionInt Method

Definition

Sets an option to a integer value.

SetOptionInt(name, value)

Parameters

namestr

The option's dotted path.

valueint

The value.

Returns

None.

Remarks

The option is created when missing (with its missing parents, which are made persistent); when its value changes, the option observers are told (the engine applies graphics, audio and control settings this way). Written by the "usa" locale's stream (grouped thousands).
