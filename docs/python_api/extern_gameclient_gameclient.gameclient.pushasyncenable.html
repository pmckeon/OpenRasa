extern_gameclient_gameclient.GameClient.PushAsyncEnable Method

Definition

Sets whether assets load asynchronously, remembering the previous setting.

PushAsyncEnable(flag)

Parameters

flagbool

False to load synchronously.

Returns

True.

Remarks

With False the call also waits until the loader is idle and runs its completions. The front-end screens push False so their views load at once.
