extern_trmain_trmain._ShouldLog Function

Definition

Queries whether a log of type severity should be logged.

_ShouldLog(severity)

Parameters

severityint

The severity level.

ValueMeaning
0TRACE
1DEBUG
2INFO
3WARNING
4ERROR
5ASSERT
6FATAL

Returns

True if a call to _WriteLog with the same severity would be written, otherwise False.

Remarks

True when the log file exists (logging is enabled in tabula_rasa.cfg) and the level is at or above the threshold, which the release client leaves at 0 - every level is logged.

Engine

tabula_rasa.exe: FUN_00405070.
