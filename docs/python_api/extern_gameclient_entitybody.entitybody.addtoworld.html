extern_gameclient_entitybody.EntityBody.AddToWorld Method

Definition

Adds the body to the world.

AddToWorld([flags])

Parameters

flagsint

Bit 0: ignore ABVs (the collision manager); bit 1: ignore walkable surfaces.

Returns

None.

Remarks

When its model is still loading the call is queued until it has. An actor then fades in over one second. The body joins the scene unless its culling layer is 6, the collision manager by its role, and its walkable surfaces are added; the scripts get OnAddToWorldCompleted.

Engine

tabula_rasa.exe: FUN_00503800 -> FUN_00543940.
