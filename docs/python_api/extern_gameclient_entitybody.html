extern_gameclient_entitybody Module

Description

Entity bodies: the engine side of every entity the client shows - its model, place, animation, effects, sounds and collision.

Attributes

NameDescription
EntityBodyBaseClass - The base of EntityBody: place, rotation, flags, distances and decoration points.
EntityBodyClass - An entity's body, made by CreateBody.
