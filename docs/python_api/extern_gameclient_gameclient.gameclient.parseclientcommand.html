extern_gameclient_gameclient.GameClient.ParseClientCommand Method

Definition

Runs a client debug command (chat /cl_<name>).

ParseClientCommand(command, arguments)

Parameters

commandstr

cl_hue2test or cl_reloadcameras.

argumentsstr

Comma-separated arguments.

Returns

None.

Remarks

cl_hue2test r,g,b,a,r,g,b,a (0 - 255) applies a second hue to every body; cl_reloadcameras reads the camera profiles again (cameraprofiles.xml, _custom, _internal).

OpenRasa

cl_hue2test has no visible effect (the second hue is not drawn).

Engine

tabula_rasa.exe: FUN_004d6270.
