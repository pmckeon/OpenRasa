extern_gameclient_optionsmanager_wrap.OptionsManager.AddOptionBool Method

Definition

Adds an option with a boolean value, or returns the existing one.

AddOptionBool(name, value, persistent)

Parameters

namestr

The option's dotted path.

valuebool

Its value and default.

persistentbool

Whether it is saved.

Returns

The Option. An option that exists is returned unchanged; a new one gets the value as both value and default (missing parents are created, persistent) and the observers are told it was added.
