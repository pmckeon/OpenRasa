extern_gameclient_entitybody.StaticBodyAttachParticle Function

Definition

Attaches a particle system to a static map body when it loads.

StaticBodyAttachParticle(entityId, assetName, cpId)

Parameters

entityIdlong

The map entity's id.

assetNamestr

The .pfx.

cpIdint

A contact point id of the model, or -1 for the body itself.

Returns

None.

Remarks

A contact point the model lacks gets nothing ("Body missing CPID").
