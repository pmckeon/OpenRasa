extern_gameclient_optionsmanager_wrap.OptionsManager Class

Definition

The game client's options: a tree of Option nodes addressed by dotted paths (Client.Graphics.ViewDistance, User.Camera.DesiredDistance, Character....). Returned by GameClient.GetOptionsManager. The class cannot be created from Python: its __init__ raises RuntimeError "This class cannot be instantiated from Python".

Remarks

Paths are split at ., / and \; empty parts are skipped and parts are matched ignoring case. Values are stored as text: booleans as True / False, numbers written with the "usa" stream locale (grouped digits, %g, three-digit exponents).

Persistent Client.* options are saved to client.cfg, User.* and Character.* ones to the server (EndEditing).
