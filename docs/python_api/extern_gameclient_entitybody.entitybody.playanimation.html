extern_gameclient_entitybody.EntityBody.PlayAnimation Method

Definition

Plays an animation.

PlayAnimation(name[, blend[, weight[, loop[, start[, markers]]]]])

Parameters

namestr

The animation (.anm, with or without the extension).

blendfloat

Seconds to blend in (0).

weightfloat

The target weight (1).

loopbool

Loops (True).

startfloat

Start time in seconds (0).

markersstr

The .mkr whose markers to fire (optional).

Returns

True.

Remarks

Animations play together until unloaded; per bone the tracks are blended by priority (the track's flags), lowest first, each group taking min(its weight, what is left). Playing one again restarts it.
