extern_gameclient_clientmovingentitycontroller.ClientMovingEntityController Class

Definition

The client's movement controller: it moves the player's body from input and server-driven bodies from the server's movement messages, with their facing and turning. The class cannot be created from Python: its __init__ raises RuntimeError "This class cannot be instantiated from Python".

Base: MovingEntityController
