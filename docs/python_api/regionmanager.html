RegionManager Object

Definition

The map regions' features (sky, environment map, sounds, music, name), returned by GameClient.GetRegionManager (a new object each call).

Methods

MethodDescription
Transition(initial, regions)Applies the regions the player is in.
SetTransSky(flag)Sets whether region skies use the transition sky.
Reset()Resets the region state.
