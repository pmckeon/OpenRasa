extern_gameclient_option_wrap.Option Class

Definition

One node of the options tree: a name, a value, a default, a persistence flag and child options. The manager's options are addressed by path (Client.Graphics.ViewDistance); each part is a node. The class cannot be created from Python: its __init__ raises RuntimeError "This class cannot be instantiated from Python".

Remarks

Values are text; the manager's typed getters and setters convert. Get / Set methods here change the node directly and do not notify the option observers (unlike OptionsManager.SetOption...).
