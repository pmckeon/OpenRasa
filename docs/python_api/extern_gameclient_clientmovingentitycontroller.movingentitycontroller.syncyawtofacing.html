extern_gameclient_clientmovingentitycontroller.MovingEntityController.SyncYawToFacing Method

Definition

Turns the body to its facing.

SyncYawToFacing()

Returns

None.

Remarks

The current control state turns the body towards the facing's yaw at its turn rate (the player's and server-driven bodies queue a turn); without a state the yaw is set at once.
