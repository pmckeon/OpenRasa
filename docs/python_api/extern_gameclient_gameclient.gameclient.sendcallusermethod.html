extern_gameclient_gameclient.GameClient.SendCallUserMethod Method

Definition

Calls a server method on the user (a ClientMsg_CallServerMethod).

SendCallUserMethod(method, args)

Parameters

methodint or str

The method's id, or its name. A name the method table (InitializeMethodNameLookup) knows with a non-zero id is sent as that id.

argstuple

The arguments, written by the engine's value writer.

Returns

None.

Exceptions

ExceptionCondition
RuntimeError"The first argument must be an int or string" / "The second argument must be a tuple".

Remarks

Message type 6, subtype 1 by id, 2 by name. Nothing is sent without a game server connection. A value the writer cannot write sends nothing.

Engine

tabula_rasa.exe: FUN_004d48e0.
