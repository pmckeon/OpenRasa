extern_gameclient_usercontroller.UserController.ToggleCameraZoom Method

Definition

Toggles the zoomed camera (the middle mouse button).

ToggleCameraZoom()

Returns

None.

Remarks

Only in UserMode Normal; the other modes do nothing. The zoom profile is the body's <mesh>-zoom, else SetCameraZoomProfile's, else <profile>-zoom.

Engine

tabula_rasa.exe: 0x004f5db0.
