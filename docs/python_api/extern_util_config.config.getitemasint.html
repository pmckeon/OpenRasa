extern_util_config.Config.GetItemAsInt Method

Definition

Gets an item's value as an integer.

GetItemAsInt(section, key, default)

Parameters

sectionstr

The section.

keystr

The key.

defaultint

Returned when the item does not exist.

Returns

The value read by strtol with base 0 (so 0x hexadecimal and leading-zero octal are read), clamped to a 32-bit long; 0 for text that is not a number; default when the item does not exist.
