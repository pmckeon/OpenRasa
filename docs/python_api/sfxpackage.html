SfxPackage Object

Definition

A special-FX package playing on a body, returned by EntityBody.AttachFXPackage and its variants.

Methods

MethodDescription
Start([fire])Starts the package: fires marker 0.
Stop([ms])Stops the package's effects.
OnTick()Fires marker 15 (TICK).
ChangeTargets(hits, misses)Replaces the package's targets.
Disconnect()Stops the package receiving the body's animation markers.
IsPersistent()Queries whether the package is persistent.

Remarks

The handle owns the package: when the last reference goes, the package stops (and, if its file was still loading, never plays).
