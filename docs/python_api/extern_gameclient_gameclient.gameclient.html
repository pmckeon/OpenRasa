extern_gameclient_gameclient.GameClient Class

Definition

The game client. There is one, returned by trmain.GetGameClient; gameclient.py wraps it as the gameclient the scripts use. The class cannot be created from Python: its __init__ raises RuntimeError "This class cannot be instantiated from Python".
