extern_gameclient_entitybody.StaticBodySetHue Function

Definition

Sets a static map body's hues.

StaticBodySetHue(entityId, hue1, hue2)

Parameters

entityIdlong

The map entity's id.

hue1tuple

(r, g, b, a), 0 - 255.

hue2tuple

(r, g, b, a), 0 - 255.

Returns

None.

Remarks

Applied when the body loads, and only when hue1 is not (0, 0, 0, 255).

Engine

tabula_rasa.exe: 0x005131b0.
