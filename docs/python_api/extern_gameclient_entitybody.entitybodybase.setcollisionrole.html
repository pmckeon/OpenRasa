extern_gameclient_entitybody.EntityBodyBase.SetCollisionRole Method

Definition

Sets the body's collision role.

SetCollisionRole(role)

Parameters

roleint

The role.

ValueMeaning
1None.
2Restricted collider (characters, creatures, vehicles).
3Collider.
4Collidee (ABVs, doors, force fields).
5Trigger collidee.
6Trigger collidee with line of sight.

Returns

None.

Remarks

classmanager.py sets the entity class's role. The role decides which of the collision manager's lists the body joins when added to the world.
