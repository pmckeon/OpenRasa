extern_gameclient_entitybody.EntityBody.AddAccessory Method

Definition

Hangs a model on one of the body's connection points (weapons, holsters).

AddAccessory(connectionPoint, meshName[, r, g, b, a])

Parameters

connectionPointint

The socket's connection point id (HPS_).

meshNamestr

The accessory; its plug (HPP_) of the same name is joined to the socket.

r, g, b, afloat

A colour for the accessory's Diffuse / Ambient material parameters; (0, 0, 0, 1) = none.

Returns

None.

Remarks

Queued while the body loads.

Engine
