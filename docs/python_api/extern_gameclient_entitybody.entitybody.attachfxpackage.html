extern_gameclient_entitybody.EntityBody.AttachFXPackage Method

Definition

Plays a special-FX package (.pkg) on the body.

AttachFXPackage(package[, hits[, misses]])

Parameters

packagestr
hitslist

Entity ids the package's effects aim at as hits.

misseslist

Entity ids as misses.

Returns

The package's SfxPackage handle.

Remarks

The package starts at once (marker 0); the body's animation markers fire its other events. The handle is the package's only owner: when it is released while the package's file is still loading, nothing plays.
